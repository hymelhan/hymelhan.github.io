Informations

The map is currently in demo, a lot more features are yet to come.

For this demo, you will need to download the .mrpack file and set it up in a mod loader. We suggest for you to use Modrinth, Prism, Multimc or any launcher that natively supports .mrpack modpack format. It includes all required mods, the map, the datapack, the resourcepack and QoL/performance mods.

The map is not downloadable individually for this demo, but you can download both the datapack and resourcepack.
