Informations

Hymelhan is currently still in demo, so do note that many things will be incomplete.

For this demo, you will need to download the .mrpack file and set it up in a mod loader. We suggest that you use Modrinth, Prism, Multimc or any launcher that natively supports the .mrpack file format. It includes all required mods, the map, the datapack, the resourcepack and QoL/performance mods.

The map is not downloadable for this demo, but you can download both the datapack and resourcepack individually.
